### 5. Header and Include Layout

Use this standard to structure header (`.hpp`/`.h`) and implementation (`.cpp`) files to ensure fast compilation, clean dependencies, and zero compile-time namespace pollution.

---

#### 1. Header Guard Standardization
Prevent multiple inclusions of the same header using clean guard directives:

*   **Rule:** 
    *   Use `#pragma once` at the very top of all modern C++ headers and PAL/application components.
    *   Use traditional `#ifndef / #define` guards only for pure C-compatible HAL/interface headers to maintain legacy toolchain compatibility.
*   **Legacy Guard Format:**
    ```cpp
    #ifndef FILE_IHAL_H
    #define FILE_IHAL_H

    // ... interface content ...

    #endif // FILE_IHAL_H
    ```

---

#### 2. Include Ordering (The "Sandwich" Rule)
Order includes within `.cpp` files from closest (most specific) to furthest (most general). This structure implicitly validates that headers are self-contained (i.e., they compile cleanly without depending on the order of subsequent includes).

*   **Rule:** Arrange `#include` directives in implementation files using the following strict hierarchy, with a single blank line separating each logical group:

```cpp
// 1. Matching Header File
#include "HttpsServer.hpp"

// 2. Local Project / Protocol / HAL Headers
#include "PAL/Platform/Esp32/Protocol/HTTP/URIs/HttpUri.hpp"
#include "System/system.h"

// 3. Third-Party / ESP-IDF SDK Headers
#include <esp_https_server.h>
#include <mbedtls/ssl.h>

// 4. C++ Standard Library Headers (Use <c...> wrappers instead of C <....h> versions)
#include <algorithm>
#include <cstring>
#include <string>
#include <vector>
```

---

#### 3. Compile-Time Optimization (Forward Declarations, Recommended, not Mandatory)
Avoid unnecessary header compilation cascades by minimizing the inclusions of full class definitions inside `.hpp` files.

*   **Rule:** If a header file only references a class as a pointer (`*`) or reference (`&`), do **not** include its header file. Use a forward declaration instead. Include the actual header only in the `.cpp` file where the class members are accessed.
*   **Forward Declaration Template:**
    ```cpp
    #pragma once

    #include "System/system.h"
    #include <vector>

    // Forward declarations (Avoids including full headers here)
    class IHttpUri; 
    class HttpUri;
    typedef void* httpd_handle_t;

    class HttpsServer
    {
    public:
        // Pointers/References only require forward declarations
        sys_error_t registerUri(IHttpUri& uri); 
        
    private:
        httpd_handle_t        _server;         
        std::vector<HttpUri*> _registeredUris; 
    };
    ```

---

#### 4. Header Hygiene Rules
*   **Prohibition of Namespace Pollution:** Never use `using namespace` (e.g., `using namespace std;` or `using namespace HTTP_COMMON;`) in any header file. Doing so pollutes the global namespace of any file including the header.
*   **C++ Wrapper Headers:** Use C++ style standard headers (e.g., `<cstring>`, `<cstdio>`, `<cstdint>`) instead of their C counterparts (`<string.h>`, `<stdio.h>`, `<stdint.h>`) inside C++ classes.
